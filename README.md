# Diabetic-Retinopathy-Detection
Deep learning-based diabetic retinopathy detection using MobileNetV2 and CNN, with Grad-CAM visualization for identifying affected retinal regions.

A deep learning application that detects the stage of Diabetic Retinopathy from retinal fundus images using CNN and MobileNetV2.

The model classifies images into five stages:

- No DR
- Mild
- Moderate
- Severe
- Proliferative DR
Grad-CAM is used to visualize the affected retinal regions.
## Features
- Image preprocessing
- Deep Learning model
- Five-class classification
- Grad-CAM visualization
- Accuracy and loss graphs
- Confusion matrix
